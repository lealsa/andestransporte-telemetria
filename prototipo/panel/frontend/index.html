3Control manual de la anomalía

Modo: —
Cómo funciona el control manual

"Quitar anomalía" hace dos cosas: el simulador vuelve a lecturas normales y se reconoce la alerta en la API (POST /tramos/{id}/alertas/reconocer), así la tarjeta vuelve a normal al instante. Si la anomalía reaparece, el detector emite una alerta nueva (nuevo episodio) y la tarjeta vuelve a rojo en ~3–4 s.

El detector compara cada muestra (1 por segundo) contra la ficha nominal fija del tramo (detector/tramos-nominal.json: 45 bar, 120 m³/h) y confirma la anomalía tras 3 muestras consecutivas fuera de umbral (−10% de presión y ≥8 m³/h de descuadre a la vez). No hay línea base aprendida: da igual el estado en que arranque el tramo.

4Gobierno del Schema Registry

Envía al registry el esquema de telemetría con data.valor cambiado de number a string, y muestra la respuesta cruda del registry.

Qué hace cada botón

"Registrar esquemas" registra ambos subjects con schemaType: JSON y fija BACKWARD_TRANSITIVE. Es idempotente; hace falta tras cada docker compose down -v, porque el registry arranca vacío.

Si todo está bien configurado, "Probar cambio incompatible" debe responder is_compatible: false junto con la razón (TYPE_CHANGED en data.valor).
